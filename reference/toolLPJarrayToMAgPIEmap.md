# toolLPJarrayToMAgPIEmap

transforms object (array) with 67420 cells to be able to be used in
plotmap function

This tool function selects the required cells from object with 67420
cells to be able to plot using plotmap or plotmap2 that are applied to
magpie object of size 59199 cells

## Usage

``` r
toolLPJarrayToMAgPIEmap(x)
```

## Arguments

- x:

  magpie object to be transformed

## Value

magpie object with correct dimension for use in plotmap

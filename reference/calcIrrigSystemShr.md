# calcIrrigSystemShr

This function returns the share of the irrigation area under a specific
irrigation system type (surface, sprinkler, drip) per crop type

## Usage

``` r
calcIrrigSystemShr(iniyear)
```

## Arguments

- iniyear:

  Year to be used for irrigation system share initialization

## Value

magpie object in cellular resolution
